پروژه توسعه نرم‌افزار – پروژه شماره ۱


راهنمای ارسال پروژه دانشجویان


دانشجویان عزیز، برای تحویل پروژه شماره ۱، لازم است مراحل زیر را به‌ترتیب انجام دهید. ارسال پروژه از طریق GitHub و با استفاده از روش Fork و Pull Request انجام می‌شود.


مرحله اول: ایجاد نسخه شخصی از مخزن (Fork)


۱. وارد مخزن اصلی درس در GitHub شوید.


۲. روی دکمه Fork در بالای صفحه کلیک کنید.


۳. حساب کاربری خود را انتخاب کنید تا یک نسخه از مخزن در حساب GitHub شما ایجاد شود.


مرحله دوم: ایجاد پوشه اختصاصی


۱. وارد نسخه‌ای شوید که در حساب شخصی شما ایجاد شده است.


۲. پوشه Project-1 را باز کنید.


۳. داخل این پوشه، یک پوشه با نام کاربری GitHub خود ایجاد کنید.


مثال:


Project-1/your-github-username/


۴. فایل‌های پروژه خود را در این پوشه قرار دهید.


۵. نام فایل‌ها را به‌صورت واضح و منظم انتخاب کنید.


مرحله سوم: ایجاد فایل معرفی پروژه


داخل پوشه اختصاصی خود، یک فایل با نام README.md ایجاد کنید و اطلاعات زیر را در آن بنویسید:




نام و نام خانوادگی: نام کامل دانشجو


نام کاربری GitHub: نام کاربری حساب شما


عنوان پروژه: نام پروژه


توضیحات پروژه: معرفی کوتاه هدف و عملکرد پروژه


نحوه اجرا: مراحل لازم برای اجرای برنامه




مرحله چهارم: ثبت تغییرات (Commit)


۱. فایل‌های بارگذاری‌شده را بررسی کنید.


۲. یک پیام کوتاه و گویا برای تغییرات بنویسید.


۳. روی گزینه Commit changes کلیک کنید تا تغییرات در مخزن شخصی شما ثبت شوند.


مرحله پنجم: ارسال پروژه با Pull Request


۱. وارد نسخه شخصی مخزن خود شوید.


۲. از بخش Pull requests گزینه New pull request را انتخاب کنید. در صورت نمایش گزینه Contribute نیز می‌توانید از مسیر Open pull request استفاده کنید.


۳. مخزن اصلی درس را به‌عنوان مخزن مقصد (Base repository) انتخاب کنید.


۴. شاخه مقصد (Base branch) را روی main قرار دهید.


۵. مخزن شخصی خود را به‌عنوان مخزن مبدأ (Head repository) انتخاب کنید و شاخه‌ای را که تغییرات پروژه در آن ثبت شده است مشخص کنید.


۶. بررسی کنید که فایل‌های پروژه شما در فهرست تغییرات نمایش داده شوند.


۷. عنوان درخواست را با الگوی زیر وارد کنید:


Project 1 Submission – نام و نام خانوادگی


۸. توضیح کوتاهی درباره پروژه خود بنویسید.


۹. روی Create pull request کلیک کنید.


قوانین ارسال پروژه




هر دانشجو باید پروژه خود را با حساب GitHub شخصی خود ارسال کند.


نام پوشه اختصاصی باید با نام کاربری GitHub دانشجو مطابقت داشته باشد.


تمام فایل‌های پروژه باید در پوشه اختصاصی دانشجو قرار بگیرند.


از تغییر یا حذف فایل‌های سایر دانشجویان خودداری کنید.


از ارسال رمز عبور، کلیدهای API و اطلاعات محرمانه خودداری کنید.


پیش از ارسال Pull Request، تغییرات خود را بررسی کنید.


ارسال پروژه زمانی کامل است که Pull Request با موفقیت ایجاد شده باشد.




چک‌لیست نهایی تحویل پروژه




[ ] فایل‌های پروژه را بارگذاری کرده‌ام.


[ ] پوشه اختصاصی خود را ایجاد کرده‌ام.


[ ] فایل README.md را تکمیل کرده‌ام.


[ ] تغییرات را Commit کرده‌ام.


[ ] Pull Request را به مخزن اصلی درس ارسال کرده‌ام.




توجه: درخواست Pull Request را خودتان Merge نکنید. بررسی و ادغام نهایی پروژه بر عهده مدرس درس است.
