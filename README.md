# Software Development Projects

به مخزن مرکزی پروژه‌های درس توسعه نرم‌افزار خوش آمدید.

## هدف
جمع‌آوری، بررسی و معرفی پروژه‌های دانشجویان از طریق GitHub و Pull Request.

## نحوه تحویل پروژه
1. مخزن کلاس را Fork کنید.
2. پروژه خود را در پوشه اختصاصی‌تان قرار دهید.
4. تغییرات را Commit کنید.
5. برای مخزن اصلی کلاس یک Pull Request ایجاد کنید.
6. نام و نام خانوادگی و عنوان پروژه را در توضیحات درخواست بنویسید.
